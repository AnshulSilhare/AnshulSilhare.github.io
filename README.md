## 🚀 Featured Projects

Here are the projects featured on my [portfolio website](https://anshulsilhare.github.io/):

### 1️⃣ DataCo Supply Chain: AI Delivery Risk Predictor
*End-to-end Machine Learning web application to predict global shipping delays before they occur.*
- **Objective:** Transition logistics management from reactive historical tracking to proactive risk intervention.
- **Methodology:** Engineered a Random Forest classifier on 180,000+ records using Python and Scikit-Learn; processed 240+ features via One-Hot Encoding and StandardScaler.
- **Outcome:** Deployed a production-ready dashboard providing real-time, probability-based delay risk percentages for both individual and bulk order uploads.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/ai-dataco-supply-chain) | [🚀 Live Demo](https://anshulsilhare-ai-dataco-supply-chain.hf.space)
- **Key Metrics:** **180K+** Records Trained • **80%** Precision Score • **240+** Engineered Features

### 2️⃣ Rapido Logistics: Revenue Leakage & Loss Analytics
*MySQL database engineering and diagnostic analytics to recover lost revenue.*
- **Objective:** Design an operational relational database to analyze bookings, identify revenue leakage, and flag scheduling lags.
- **Methodology:** Designed a MySQL database backend with 8 normalized entities (3NF). Analyzed 30,000+ bookings.
- **Outcome:** Identified ₹251.9K in revenue leakage and flagged a 20% lead time spike in night shifts.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/Rapido_Logistics_Analytics_SQL)
- **Key Metrics:** **30K+** Bookings Analyzed • **₹251.9K** Leakage Identified • **20%** Night Shift TAT Lag

### 3️⃣ Amazon Logistics Network Optimisation
*Strategic network digital twin to achieve 90% US coverage within 48 hours.*
- **Objective:** Design a "Lean 5-Node" distribution network to balance freight costs vs. speed.
- **Methodology:** Conducted Transit Time Analysis and geodesic network modeling using Excel Solver and Python Folium.
- **Outcome:** Consolidated 15 nodes into 5 regional distribution centers, achieving 94% customer population coverage.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/Logistics-Network-Optimization) | [🗺️ Interactive Map](https://AnshulSilhare.github.io/Logistics-Network-Optimization/map.html)
- **Key Metrics:** **5-Node** Hub-and-Spoke model • **94%** Population Coverage • **-18%** Fuel Consumption

### 4️⃣ Pharma Demand Forecasting: Model Selection
*Matching the mathematics of forecasting to SKU demand behavior.*
- **Objective:** Solve high stockout/expiry volatility for a multi-product portfolio.
- **Methodology:** Applied **Exponential Smoothing (Alpha = 0.5)** to react to demand surges for volatile SKUs, and **Moving Averages** to filter noise for stable lines.
- **Outcome:** Reduced procurement lag and optimized safety stock levels to prevent stockouts.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/Pharma-Demand-Forecasting)
- **Key Metrics:** Dual-Engine Model selection • **SKU Volatility** Profiling • Procure Lag Mitigation

### 5️⃣ SQL Data Warehouse: Medallion Architecture
*Production-grade enterprise data warehouse on SQL Server.*
- **Objective:** Centralize and clean siloed data from ERP and CRM systems.
- **Methodology:** Engineered a 3-layer Medallion architecture (Bronze, Silver, Gold) on SQL Server. Programmed pure T-SQL ETL pipelines to serve dimensional models (Star Schema).
- **Outcome:** Delivered business-ready fact and dimension tables, serving cleaned and validated data for analytics.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/sql-data-warehouse-project)
- **Key Metrics:** **3-Layer** Medallion • **Star Schema** Models • **Pure T-SQL** ETL (no 3rd-party tools)

### 6️⃣ Data Analyst Job Market Analysis: Python
*Jupyter-based statistical analysis of 100,000+ real US job postings.*
- **Objective:** Replaced subjective career advice with empirical market intelligence on in-demand data skills.
- **Methodology:** Extracted and processed 785,000+ skill mentions using Python and Pandas; engineered ROI models visualized with Matplotlib and Seaborn.
- **Outcome:** Proved SQL's market dominance (51% demand rate) over Python for data analysts.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/us-data-jobs-analysis) | [🚀 Live Demo](https://anshul-job-market.streamlit.app)
- **Key Metrics:** **100K+** Job Postings • **51%** SQL Demand • **$98K** Python Median Salary

### 7️⃣ Warehouse Layout Optimization: Flow Engineering
*Facility design optimization to resolve picking bottlenecks.*
- **Objective:** Eliminate layout overlaps and excessive picker travel distance.
- **Methodology:** Mapped high-turnover SKUs closer to packing lanes using ABC Analysis; implemented a "Cross-Dock" layout with segregated Inbound/Outbound zones.
- **Outcome:** Optimized warehouse picker workflows to prevent bottlenecks.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/Warehouse-Layout-Optimization)
- **Key Metrics:** **ABC Analysis** SKU Slotting • Segregated lanes • **20%** Throughput Capacity Increase

### 8️⃣ Medical Device Supply Chain: Value Stream Mapping
*Visualizing the gap between planning and reality in manufacturing.*
- **Objective:** Identify lead-time bottlenecks and shadow inventory skewing planning models.
- **Methodology:** Mapped the logistics flow using Lucidchart process streams.
- **Outcome:** Exposed a **96+ hour bottleneck** at off-site sterilization and audited sales rep "Trunk Stock".
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/Value-Stream-Mapping)
- **Key Metrics:** **96+ Hours** process lag exposed • rep Trunk Stock audit • process flow redesign

### 9️⃣ Consumer Behavior: The Personalization Paradox
*Quantitative study using SPSS to analyze personalization vs. privacy.*
- **Objective:** Analyze the relationship between algorithm intrusiveness and user trust in e-commerce.
- **Methodology:** Formulated and analyzed survey responses (N=130) using Chi-Square and Spearman's Rank tests in SPSS.
- **Outcome:** Found a strong negative correlation (r = -0.47) between intrusiveness and data sharing, and a positive correlation (r = 0.68) between trust and repurchasing.
- **Links:** [📁 GitHub Repository](https://github.com/AnshulSilhare/Consumer-Behavior-Research)
- **Key Metrics:** **N=130** survey size • **r = -0.47** correlation • **r = 0.68** trust coefficient
